# 立创EDA 文件（可生成PCB）

## 为什么不是 SVG / .epro2？

- **SVG** 只是绘图格式，任何 EDA 软件都无法把 SVG 转成 PCB
- **`.epro2`** 是立创EDA专业版私有格式（本仓库解剖过官方瓦力机器人样例：
  内部是 9.8 万行私有 JSON，含矢量化字体缓存与符号基元，手工生成无法保证可打开）
- **能导入的是**：立创EDA标准版 JSON ✅（本目录）· KiCad 工程 · Altium 工程

## 导入步骤

1. 打开 **立创EDA专业版**（pro.lceda.cn 或客户端）
2. 菜单：**文件 → 导入 → 立创EDA标准版**
3. 选择本目录的 `demo3_robot_s3_schematic.json`
4. 得到一张模块级原理图（J1~J8 + R1）：
   - J1 = ESP32-S3-DevKitC-1 的全部使用引脚（竖排排针）
   - J2 INMP441 / J3 MAX98357A / J4 OLED / J5 J6 舵机 / J7 LDR / J8 触摸
5. 检查网络标号无误后：**设计 → 原理图转PCB**
6. 在 PCB 里为 J1~J8 选择封装（推荐 JLC 器件库的 2.54mm 排针/XH2.54 卧贴），
   摆好后布线 → 覆铜 → **一键下单**嘉立创打板

## 元件采购建议（对应原理图网络）

| 位号 | 内容 | 立创商城关键词 |
|------|------|----------------|
| J1 | 2.54mm 排针 1×16（焊 DevKitC 所用引脚）| 排针 2.54 单排 16P |
| J2 | INMP441 模块 → XH2.54-6P 卧贴 | XH2.54 6P 卧贴 |
| J3 | MAX98357A 模块 → XH2.54-8P（或 7P+悬空 GAIN）| XH2.54 8P |
| J4 | OLED → XH2.54-4P | XH2.54 4P |
| J5/J6 | 舵机 → 2.54 直排 3P | 舵机线序: 橙信号红VCC棕GND |
| J7/J8/R1 | 光敏+10K 0603 + 单排针 | 光敏电阻 GL5528 |
