# 🔌 硬件接线说明

| 外设 | 外设引脚 | ESP32 引脚 | 备注 |
|------|----------|-----------|------|
| **OLED SSD1306** | VCC | 3V3 | I2C 地址默认 0x3C |
| | GND | GND | |
| | SCL | GPIO22 | |
| | SDA | GPIO21 | |
| **舵机 水平(pan)** | 信号(橙) | GPIO25 | |
| **舵机 垂直(tilt)** | 信号(橙) | GPIO26 | |
| **无源蜂鸣器** | 正极 | GPIO27 | 无源！有源的不行 |
| **光敏 LDR** | 分压输出 | GPIO34 | 见下方分压说明 |
| **触摸(摸头)** | 裸线/锡箔 | GPIO4 (T0) | 一根杜邦线+锡箔纸即可 |
| **状态LED** | — | GPIO2 | 板载 LED，无需接线 |

## ⚠️ 舵机供电（重要！）

SG90 堵转电流可达 **650mA+**，**不要**直接从 ESP32 的 5V 引脚取电（USB 供电带不动会导致复位）：

```
外部 5V 电源 (≥2A)
   ├──► 舵机1 红线 (VCC)
   ├──► 舵机2 红线 (VCC)
   └──► GND ──┬── ESP32 GND   ← 必须共地！
              └── 舵机棕线 (GND)
```

## 光敏电阻分压接法

```
3V3 ── LDR ──┬── GPIO34
             └── 10KΩ ── GND
```
> 光线越亮 → GPIO34 电压越高 → 读数越大（`config.h` 中 `LDR_DARK_VALUE=800` 为"天黑"阈值，4095 满量程）

## 摸头传感器（零成本方案）

一根杜邦线一头插 **GPIO4**，另一头剥出 1-2cm 裸线（或贴一小片锡箔纸）。
开机时会自动校准基线，手指触碰时电容变化触发「摸头」事件。

## 结构建议

```
        ┌─ OLED(脸) ─┐
   ┌────┴────────────┴────┐
   │      ESP32 DevKit     │  ← 舵机 pan 装在底盘
   │  [tilt舵机托OLED]     │  ← 舵机 tilt 让脸上下动
   └──┬─────────────┬──────┘
   [pan舵机]      [蜂鸣器]
```
